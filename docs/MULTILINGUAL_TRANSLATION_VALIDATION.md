무결성 검사는 원문/번역 개수 일치, 빈 원문·번역 0개, 한국어 문자가 없는 번역 0개, 두 줄 초과 0개, 줄당 23자 초과 0개, 임의 말줄임표 0개를 기준으로 했다. 중국어와 러시아어는 발견된 결함을 수정한 뒤 최종 작업을 다시 실행했다.

영어·러시아어·독일어·프랑스어의 경고는 번역 실패가 아니라 `max_cps` 15 초과다. 1분에 맞춘 빠른 합성 발화가 Whisper에서 짧은 cue로 많이 분리된 테스트 조건의 영향이며, 작업 자체와 모든 번역 cue는 보존됐다. 실제 제작물에서는 말하기 속도나 cue 병합을 조정하고 경고 구간을 검토해야 한다.

## 테스트에서 발견하고 수정한 결함

- 러시아어가 UI와 API 허용 언어 목록에서 빠져 있던 문제
- 모델이 배치의 일부 항목을 누락하면 전체 작업이 실패하던 문제
- 모델이 빈 번역을 반환해도 완료 처리되던 문제
- 긴 번역을 말줄임표로 조용히 잘라 원문 의미가 유실되던 문제
- 긴 번역이 46자 제한을 지키지 않을 때 안전한 압축 번역 단계가 없던 문제
- 번역은 완료됐지만 QA 경고가 있으면 일반 자동 자막 완료 문구가 표시되던 문제

개별 실행 작업 ID와 원본 음성 파일은 공개 저장소에 포함하지 않는다.
